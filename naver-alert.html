YBM 네이버 예약 알림

윈도우 PC용 프로그램 · 강사 상담 예약이 추가·취소되면
화면 오른쪽 아래에 알려 드려요.

📱 휴대폰에서는 설치할 수 없어요. PC에서 이 링크를 열어 주세요.
(PC 카카오톡에서 같은 링크를 누르거나, 아래 ‘링크 복사’ 후 PC로 보내기)
⬇ 설치 파일 받기 (약 100KB)

설치 방법 (1분)

  1. 설치 파일 받기를 누릅니다. 브라우저가 ‘일반적으로 다운로드되지 않는 파일’이라고 하면 … 또는 ⌃ → 유지
  2. 받은 파일을 실행합니다. ‘Windows의 PC 보호’ 창이 뜨면 글자 아래 추가 정보 → 실행 (설치할 때 PC마다 한 번만 떠요)
  3. ‘설치할까요?’에서 확인 → 끝. 관리자 권한은 필요 없어요. 예약 현황 창과 ‘설치가 끝났습니다’ 알림이 뜨면 완료예요.

설치하고 나면

  • 윈도우를 켜면 자동으로 실행되어 2분마다 확인합니다. 따로 열 필요 없어요.
  • 예약이 추가·취소되면 오른쪽 아래 알림창이 ‘확인’을 누를 때까지 남아 있어요.
  • 작업 표시줄 오른쪽 아래 달력 아이콘을 누르면 날짜별 예약 현황을 볼 수 있어요 (안 보이면 ^ 안에).
  • PC가 꺼져 있던 동안의 변동은 다음에 켜면 알려 드려요.
  • 제거: 설정 → 앱 → 설치된 앱 → ‘YBM 네이버 예약 알림’ → 제거

안전 정보

  • 네이버 예약의 공개 정보(시간대별 예약 수)만 확인하며, 개인정보·비밀번호를 저장하지 않아요.
  • ‘Windows의 PC 보호’는 위험하다는 뜻이 아니라, 인증서 서명이 없는 새 프로그램이라 뜨는 경고예요.
  • 파일 확인값(SHA-256): —
    다른 경로로 받은 파일은 PowerShell에서 Get-FileHash 파일이름.exe 결과와 같은지 확인하세요.
